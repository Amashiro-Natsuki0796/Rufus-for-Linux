# 第 3 章　构建、打包与安装指南

---

## 3.1　环境要求

- 操作系统：Debian 12/13、Ubuntu 22.04/24.04 或兼容发行版（x86_64 / aarch64）
- 编译器：GCC 9+ 或 Clang 12+
- 图形界面：GTK3 开发包（可选，缺失时自动跳过 GUI 构建）

### 依赖安装（Debian / Ubuntu）

```bash
sudo apt-get update
sudo apt-get install -y \
    build-essential make pkg-config \
    libgtk-3-dev libglib2.0-dev \
    dh-make debhelper devscripts lintian fakeroot

# 运行时功能依赖（制作启动盘时需要）
sudo apt-get install -y \
    util-linux coreutils dosfstools gdisk \
    exfatprogs ntfs-3g parted \
    syslinux syslinux-common isolinux udftools
```

各运行时工具的用途：

| 工具 | 提供者 | 用途 |
| --- | --- | --- |
| `mkfs.vfat` | dosfstools | FAT16/FAT32 格式化 |
| `mkfs.exfat` | exfatprogs | exFAT 格式化 |
| `mkfs.ntfs` | ntfs-3g | NTFS 格式化 |
| `mkfs.ext4` | e2fsprogs | ext4 格式化 |
| `mkudffs` | udftools | UDF 格式化 |
| `sgdisk` / `sfdisk` | gdisk / util-linux | 分区表检查（本程序自己写分区表，这两个只用于验证/排错） |
| `syslinux` | syslinux | 安装 BIOS 引导器 |
| `mount` / `umount` | util-linux | 挂载 ISO 与目标分区 |

> 注意：本程序**自身不依赖** `parted`/`sgdisk` 来创建分区表——
> MBR 与 GPT 由 `src/core/rf_part.c` 直接按规范构造写入。这两个工具
> 仅用于人工验证。

## 3.2　从源码构建

```bash
tar xf rufus-linux-1.0.0.tar.gz      # 或 git clone 后进入目录
cd rufus-linux

make                  # 构建 CLI + GUI（默认 -O2）
```

产物：

| 文件 | 说明 |
| --- | --- |
| `build/rufus` | 命令行程序 |
| `build/rufus-gtk` | GTK3 图形界面 |
| `build/librufuscore.a` | 核心静态库（含移植的第三方模块） |

只构建命令行（无 GTK 环境）：

```bash
make cli
```

### 构建变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PREFIX` | `/usr/local` | 安装前缀 |
| `OPT` | `-O2` | 优化级别 |
| `CC` | `gcc` | 编译器 |
| `CFLAGS` | 空 | 追加编译选项 |
| `LDFLAGS` | 空 | 追加链接选项 |

示例：

```bash
make OPT="-O3 -march=native" CC=clang
PREFIX=/usr make install
```

## 3.3　安装与卸载

```bash
sudo make install                 # 安装到 /usr/local
sudo make PREFIX=/usr install     # 安装到 /usr
sudo make PREFIX=/usr uninstall   # 卸载
```

安装内容：

```
/usr/local/bin/rufus
/usr/local/bin/rufus-gtk
/usr/local/share/applications/rufus-linux.desktop
/usr/local/share/icons/hicolor/256x256/apps/rufus-linux.png
/usr/local/share/man/man1/rufus.1
/usr/local/share/doc/rufus-linux/            # 本套技术文档
```

支持 `DESTDIR`（打包时使用）：

```bash
make install DESTDIR=/tmp/stage PREFIX=/usr
```

## 3.4　构建 .deb 安装包

### 方式一：一键构建

```bash
make deb
```

等价于 `dpkg-buildpackage -us -uc -b`，产物在**上一级目录**：

```
../rufus-linux_1.0.0-1_amd64.deb
```

### 方式二：标准 Debian 流程

```bash
dpkg-buildpackage -us -uc -b          # 只构建二进制包
dpkg-buildpackage -us -uc             # 二进制 + 源码包
debuild -us -uc -b                    # devscripts 封装
```

### 打包相关文件

| 文件 | 作用 |
| --- | --- |
| `debian/control` | 包元数据、构建依赖、运行依赖 |
| `debian/rules` | 构建规则（`dh $@ --buildsystem=makefile` + 覆盖 `dh_auto_*`） |
| `debian/changelog` | 版本与变更记录 |
| `debian/copyright` | 版权与许可（含逐目录来源标注） |
| `debian/source/format` | `3.0 (native)` |
| `debian/README.source` | 源码结构说明 |

### 安装 / 卸载 / 查看

```bash
sudo dpkg -i ../rufus-linux_1.0.0-1_amd64.deb
sudo apt-get -f install          # 自动补齐依赖

dpkg -L rufus-linux              # 查看安装的文件
dpkg -s rufus-linux              # 查看包信息
sudo apt-get remove rufus-linux  # 卸载
```

### 质量检查

```bash
lintian ../rufus-linux_1.0.0-1_amd64.deb
```

## 3.5　打包依赖关系说明

`debian/control` 中的依赖划分：

- **Depends**（缺少则程序无法完成核心工作）：
  `util-linux`（mount/umount/BLKRRPART）、`coreutils`（cp/dd）、
  `dosfstools`（FAT32 —— 几乎所有启动盘都要用）、`gdisk`。
- **Recommends**（按需安装）：
  `exfatprogs`、`ntfs-3g`（Windows 大 install.wim 场景）、`parted`、
  `syslinux` + `syslinux-common`（Linux ISO 的 BIOS 引导）、`udftools`。
- **Suggests**：`wimtools`、`p7zip-full`（WIM 处理，本项目暂未使用）。

选择 Depends 还是 Recommends 的原则是：**不做这个文件系统就不需要**的
工具放 Recommends，这也是 Debian 对"可选功能"的标准处理方式。

## 3.6　常见构建问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `未找到 GTK3 开发包，跳过图形界面构建` | 缺少 `libgtk-3-dev` | `sudo apt install libgtk-3-dev`，或只用 `make cli` |
| `fatal error: cdio/iso9660.h: No such file` | 第三方头文件未随源码提供 | 确认 `src/third_party/libcdio/cdio/` 存在 |
| `undefined reference to cdio_open` | `cdio_shim.c` 未参与编译 | 确认 `src/third_party/libcdio/cdio_shim.c` 存在，且 Makefile 的 `CDIO_SRC` 含 `$(CDIO_DIR)/*.c` |
| `undefined reference to write_ntfs_br` 参数不匹配 | ms-sys 的 `write_ntfs_br(FILE*)` 只接受一个参数 | 见 `rf_mbr.c` 中的调用（已修正） |
| `_GNU_SOURCE redefined` 警告 | Makefile 与源文件同时定义 | 源文件中已用 `#ifndef` 包裹 |

## 3.7　交叉编译

代码仅依赖 POSIX 与 GTK3，在 aarch64 上可直接构建：

```bash
sudo apt install crossbuild-essential-arm64 libgtk-3-dev:arm64
dpkg-buildpackage -a arm64 -us -uc -b
```

或本机构建：

```bash
make CC=aarch64-linux-gnu-gcc \
     PKG_CONFIG_PATH=/usr/lib/aarch64-linux-gnu/pkgconfig \
     OPT="-O2"
```

## 3.8　开发工作流建议

```bash
make clean && make -j$(nproc)         # 全量重建
make cli                              # 快速迭代核心逻辑
./build/rufus help                    # 冒烟测试
./build/rufus list                    # 设备枚举（无需 root）
sudo ./build/rufus write -n img /dev/sdb
```

调试：

```bash
gdb --args sudo ./build/rufus create --force img /dev/loop0
sudo strace -f -e trace=openat,ioctl,pread64,pwrite64 ./build/rufus ...
```

使用回环设备做无风险测试：

```bash
dd if=/dev/zero of=/tmp/test.img bs=1M count=512
sudo losetup -P -f --show /tmp/test.img        # 假设输出 /dev/loop0
sudo ./build/rufus part -y --scheme gpt /dev/loop0
sudo ./build/rufus format -y --force --fs fat32 --label TEST /dev/loop0p1
sudo sgdisk -v /dev/loop0                      # 验证 GPT 正确性
sudo ./build/rufus create -n -y --force iso /dev/loop0
sudo losetup -d /dev/loop0
```
